# Перші кроки: від нуля до першого конспекту

[English](QUICKSTART.md) · [Головна](../README.uk.md) · [Питання й відповіді](FAQ.uk.md)

Займе близько 10 хвилин. Потрібні: комп'ютер з Windows, macOS або Linux, інтернет і обліковий запис Google
(для безкоштовного ключа моделі). Програмувати не треба — усе робиться в меню.

## 1. Встановлення

**Windows.** Натисніть Пуск, введіть `PowerShell`, відкрийте його й вставте по черзі (кожен рядок — Enter):

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

Закрийте вікно PowerShell, відкрийте нове й вставте:

```powershell
uv tool install backlog-digest
```

```powershell
uv tool update-shell
```

Ще раз закрийте й відкрийте PowerShell.

**macOS і Linux** — те саме в Терміналі, перший рядок інший:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

> `uv` — невелика програма, яка сама ставить потрібний Python і backlog-digest окремо від решти системи.
> Права адміністратора не потрібні.

## 2. Перший запуск

```bash
bdig
```

Відкриється майстер. Він запитає:

1. **Мову** інтерфейсу й конспектів.
2. **Теку для конспектів.** Якщо користуєтеся Obsidian — вкажіть теку сховища (там, де тека `.obsidian`).
   Якщо ні — будь-яку теку, наприклад `D:\Конспекти`: туди ляжуть звичайні файли Markdown.
3. **Ключ моделі.** Найпростіше — безкоштовний ключ Gemini:
   1. відкрийте <https://aistudio.google.com/apikey> і увійдіть своїм обліковим записом Google;
   2. натисніть **Create API key** і скопіюйте ключ;
   3. вставте його в майстрі (символи не відображаються — так і має бути). Програма перевірить ключ і
      збереже його лише на вашому комп'ютері.
4. **Перше джерело** — див. наступний розділ.
5. **Скільки на день** і чи вмикати **щоденний розклад**.

Наприкінці майстер одразу зробить перший конспект. Повторити майстер: меню → 8 → 8.

**Ярлик на робочому столі:** `bdig shortcut` — далі програма відкривається подвійним клацанням.

## 3. Як дати програмі доступ до своїх списків

Програма нічого не змінює у ваших YouTube, закладках чи Telegram — лише читає.

### YouTube

Меню → **2 Джерела** → **1 YouTube** → вставте посилання (по одному в рядку, порожній рядок — готово).

| Що | Яке посилання | Чи потрібен вхід |
|---|---|---|
| Публічний плейлист | адреса сторінки плейлиста (`...playlist?list=...`) | ні |
| Плейлист «За посиланням» | так само | ні |
| Канал | `https://www.youtube.com/@назва` або просто `@назва` | ні |
| Окреме відео | адреса відео | ні |
| **Приватний плейлист** | адреса плейлиста | так — див. нижче |
| **«Дивитися пізніше»** | `WL` | так — див. нижче |

**Як скопіювати посилання на плейлист:** на youtube.com → ліворуч «Ви» → «Плейлисти» → відкрийте плейлист
→ скопіюйте адресу з рядка браузера.

**Закриті списки.** Програма сама помітить, що список закритий (🔒), і запропонує два способи:

1. **Найпростіший і найбезпечніший — відкрити плейлист «За посиланням».** На YouTube: відкрийте плейлист →
   ⋮ (або олівець) → **Доступ** → **За посиланням**. Його не видно в пошуку й на каналі, але програма
   зможе його прочитати без входу.
   «Дивитися пізніше» так відкрити не можна, але можна скопіювати: відкрийте його → ⋮ → **Додати все до…**
   → створіть новий плейлист «За посиланням» і дайте програмі його.
2. **Файл cookies.txt** — якщо список має лишатися приватним:
   1. у браузері, де ви увійшли в YouTube, встановіть розширення **Get cookies.txt LOCALLY**
      (Chrome, Edge, Firefox);
   2. відкрийте youtube.com, натисніть на значок розширення → **Export** → збережіть файл, наприклад
      `D:\Конспекти\cookies.txt`;
   3. коли програма попросить, вкажіть шлях до цього файлу. Вона перевірить доступ і покаже, скільки відео
      бачить.

   ⚠️ Цей файл — ключ до вашого облікового запису Google. Не надсилайте його нікому й не кладіть у спільні
   теки. Програма лише читає його на вашому комп'ютері. Коли доступ зникне (через кілька тижнів), експортуйте
   знову в той самий файл.

Командою: `bdig add "https://www.youtube.com/playlist?list=..." --cookies "D:\Конспекти\cookies.txt"`.

### Книги й документи

Меню → 2 → **2 Тека** → повний шлях до теки (можна синхронізовану: Google Drive, OneDrive, Dropbox).
Підтеки стають окремими списками. PDF, EPUB, FB2, DOCX, ODT, RTF, TXT, MD, HTML читаються одразу.

### Закладки браузера й статті

Спершу збережіть закладки у файл:
- **Chrome / Edge:** `Ctrl+Shift+O` → ⋮ угорі праворуч → **Експортувати закладки**;
- **Firefox:** `Ctrl+Shift+O` → **Імпорт і резервні копії** → **Експорт закладок у HTML**.

Далі меню → 2 → **3 Статті** → шлях до збереженого файлу. Програма покаже теки закладок — виберіть потрібні
(тисячі закладок краще брати частинами). Можна й просто вставити посилання на статті.

### Raindrop.io

1. <https://app.raindrop.io/settings/integrations> → **Create new app** (назва будь-яка) → відкрийте її →
   **Create test token** → скопіюйте.
2. Меню → 2 → **4 Raindrop** → вставте токен → виберіть колекції.

### Telegram («Збережене», канали, групи)

Меню → 2 → **5 Telegram**, далі один із двох способів:

**Публічний канал — просто посилання.** Виберіть **2** і вставте `t.me/назва` (або `@назва`), по одному в рядку.
Публічний канал може читати будь-хто без облікового запису, тож ні експорт, ні вхід не потрібні. Нові публікації
додаються самі під час кожного оновлення (розклад); старі публікації великого каналу читаються частинами за
кілька оновлень. Командою: `bdig add t.me/назва`.

**«Збережене», ваші приватні канали, групи — експорт.**
1. У **Telegram Desktop**: Налаштування → Розширені → **Експорт даних Telegram** (або в чаті ⋮ → Експорт
   історії чату). Формат можна залишити HTML. Позначте потрібне: **Приватні канали** — ваші канали для нотаток,
   **Публічні канали**, і файли, якщо потрібні документи й голосові.
2. Виберіть **1** → тека експорту → номери потрібних чатів (Enter — усі). Новіший експорт у ту саму теку
   додасть лише нове.

## 4. Конспекти

Меню → **3 Зробити конспекти** → Enter. Програма покаже, що робить, і складе нотатки у вашу теку.
Ctrl+C зупиняє будь-якої миті — наступного разу вона продовжить з того самого місця.

**Чому не все одразу.** Безкоштовні ключі мають добові ліміти, а YouTube не любить частих запитів, тому
програма працює потроху: приблизно до 30 відео й кількох сотень статей на день. Найзручніше — розклад:
меню → **6** → додати завдання й увімкнути автозапуск. Далі все робиться саме, щодня.

## 5. Що далі

- **Читайте нотатки** в Obsidian чи будь-якому редакторі Markdown: оцінка, вердикт «дивитися / прочитати /
  вистачить конспекту / пропустити», головні тези, сумнівні твердження.
- **Сортування за темами + звіт** (меню → 4): теми, повтори, найкраще — в індексній нотатці списку.
- **Питання до бібліотеки** (меню → 9): відповідь з усіх ваших конспектів з посиланнями на нотатки.
- **Claude, Cursor та інші помічники** можуть читати вашу бібліотеку: `bdig mcp --config`.
- **Нове у списках** програма знаходить сама (розклад) або за меню → 2 → 6.

## Якщо щось не так

- **`bdig` не знаходиться** — закрийте й знову відкрийте термінал; не допомогло — `uv tool update-shell`.
- **Перевірка всього:** меню → 7 або `bdig doctor` — покаже, чого бракує і що з цим робити.
- Інші питання — у [FAQ](FAQ.uk.md).

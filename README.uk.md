# backlog-digest

**Розбери свої завали.** Тисячі збережених відео, статей і книг → бібліотека, яку можна прочитати за вечір.

[English](README.md) · **[Перші кроки](docs/QUICKSTART.uk.md)** · [Питання й відповіді](docs/FAQ.uk.md) · [Приклад конспекту](docs/examples/video-summary.uk.md) ·
Ліцензія: [MIT](LICENSE)

Для кожного елемента backlog-digest пише конспект із **критичною оцінкою** й чесним вердиктом **«варто чи ні»**,
позначає псевдонауку, розкладає все за темами, знаходить повтори й складає результат у **ваше** сховище Obsidian,
звичайну теку Markdown або Raindrop.io. Працює на вашому комп'ютері з безкоштовними ключами моделей, розбирає
тисячі елементів потроху щодня й ніколи не губить прогрес.

```text
╭─ 📚 backlog-digest 1.2.0 ────────────────────────────────────────────────────────────────────────╮
│ 📦 готово 16 з 84, у черзі 66                                                                    │
│ 🕒 чекають субтитрів: 44 (сьогодні зібрано 0 з 30) · готові до конспекту: 22 · без тексту: 2     │
│ 📥 Джерела: 2 (YouTube 1, Raindrop 1)                                                            │
│ 📁 Конспекти → D:\Obsidian\Бібліотека                                                            │
│ 🤖 Моделі: доступно 6 з 7 · ліміт на сьогодні вичерпано: gemini/gemini-3-flash-preview           │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Меню ───────────────────────────────────────────────────────────────────────────────────────────╮
│ 1  📊 Статистика                                             6  📅 Розклад                       │
│ 2  📥 Джерела: YouTube, папки, статті, Raindrop, Telegram    7  🩺 Перевірка (doctor)            │
│ 3  📝 Зробити конспекти                                      8  🔧 Налаштування                  │
│ 4  🧭 Сортування за темами + звіт                            9  ❓ Питання до бібліотеки         │
│ 5  🔖 Експорт у Raindrop.io                                  q  🚪 Вихід                         │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
```

## Що виходить

Нотатка на кожен елемент ([повний приклад](docs/examples/video-summary.uk.md)):

> **Measles Explained — Vaccinate or Not?** · Kurzgesagt
>
> **Вердикт: Дивитися** · Оцінка: 5/5 ★★★★★
>
> **Про що:** як вірус кору обходить імунну систему і чому щеплення важливі для колективного імунітету.
> **Ключові ідеї та факти:** 10 пунктів із цифрами · **Що нового** · **Обґрунтованість:** рівень доказів,
> на що спирається автор, сумнівні твердження · **Скільки «води»:** ~10%, з позначками часу · **Для кого** ·
> **Чому такий вердикт**

Вердикти: *Дивитися / Читати*, *Переглянути частину* (які саме фрагменти), *Достатньо конспекту*, *Пропустити*.
Шкала оцінок навмисно сувора: звичайний матеріал отримує 3, ненаукове — «Пропустити».

Далі — для кожного списку:

- **Сортування за темами** — ваші теми, кошики «важливо / решта» або дерево тем, яке запропонує модель;
  нотатки переносяться в теки тем лише після попереднього перегляду.
- **Індекс списку** — найкращі, усе за темами з оцінками, **групи повторів** (досить подивитися найкраще),
  не в темі, ненаукове, сторінки з помилками.
- **Експорт у Raindrop.io** — вкладені колекції за списками й темами, конспект — у нотатці закладки.

## Встановлення

> Уперше? Покрокова інструкція [«Перші кроки»](docs/QUICKSTART.uk.md): встановлення, ключ моделі й доступ до ваших плейлистів, зокрема приватних і «Дивитися пізніше».

Знадобиться лише [uv](https://docs.astral.sh/uv/) — невелика програма, яка сама поставить потрібний Python
і backlog-digest окремо від решти системи. Права адміністратора не потрібні.

**1. Встановіть uv** (один раз). Windows — у PowerShell:

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

macOS і Linux — у Терміналі:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

**2. Встановіть backlog-digest**, потім закрийте й знову відкрийте вікно терміналу:

```bash
uv tool install backlog-digest
uv tool update-shell
```

**3. Запустіть:**

```bash
bdig
```

Під час першого запуску майстер за кілька хвилин усе налаштує — мову, теку для конспектів, ключ моделі,
перше джерело, скільки на день, щоденний розклад — і одразу зробить перший конспект. Повторно: `bdig setup`.
`bdig shortcut` — ярлик на робочому столі (програма відкривається в окремому вікні); `bdig doctor` — перевірка,
чи все на місці.

**Ключ моделі.** Найпростіше — безкоштовний ключ Google Gemini: відкрийте <https://aistudio.google.com/apikey>,
увійдіть, «Create API key», вставте в майстрі (меню → 8 → 4). Ключі OpenRouter і DeepSeek теж підходять —
вони запасні, коли в однієї моделі скінчився добовий ліміт.

Оновлення — `uv tool upgrade backlog-digest`. Видалення — `bdig autostart off`, потім
`uv tool uninstall backlog-digest` (конспекти лишаються у вашій теці).

## Джерела

### YouTube

Без Google Cloud і без ключів YouTube. Меню → 2 Джерела → 1 → посилання на плейлист, канал (`@назва`) або відео.
Публічні плейлисти й плейлисти «За посиланням» видно без входу. Приватні й «Дивитися пізніше» — програма сама
помітить і запропонує або відкрити плейлист «За посиланням», або файл cookies.txt
([як це зробити](docs/QUICKSTART.uk.md#youtube)).

Обробка має два незалежні кроки — їх можна робити разом або окремо, у різний час:
- **зібрати субтитри** — повільно, з вашої інтернет-адреси, моделі не потрібні. Тексти лежать у базі,
  доки не готовий конспект, потім видаляються;
- **зробити конспекти** із зібраного — YouTube не потрібен, швидко, скільки дозволяють ліміти моделей.

Коли YouTube тимчасово обмежив вашу адресу, конспекти з уже зібраного далі робляться, а коли скінчились
ліміти моделей — далі збираються субтитри. Між запитами субтитрів — випадкова пауза 1–3 хв і не більше
30 запитів на добу (`[youtube] delay_min/delay_max`, `[limits] per_day` у `config.toml`). Відео без субтитрів
з ключем Gemini «дивиться» сам Gemini (довгі — частинами) або їхнє мовлення розпізнається на вашому
комп'ютері (необов'язковий Whisper); інакше вони отримують статус «без тексту» — див. [FAQ](docs/FAQ.uk.md). Те саме відео в кількох списках конспектується один раз.

### Книги й документи з папки

Меню → 2 → 2 → повний шлях до теки (можна синхронізовану: Google Drive, OneDrive, Dropbox). Підтеки першого
рівня стають окремими списками.

- Формати: PDF, EPUB, FB2 (і .fb2.zip), DOCX, ODT, RTF, HTML, TXT, MD — без додаткових програм;
  DJVU — безкоштовна DjVuLibre; MOBI, AZW3, DOC — безкоштовна Calibre (`bdig doctor` покаже, чи знайдено).
- Аудіо й відео (MP3, M4A, WAV, OGG, FLAC, MP4, MKV, WEBM, MOV…) — подкасти, лекції, аудіокниги — з
  необов'язковим розпізнаванням мовлення `backlog-digest[whisper]` (див. [FAQ](docs/FAQ.uk.md)).
- Довга книга читається частинами: спершу робочі нотатки частин, потім підсумковий конспект; після зупинки
  продовжується з того самого місця.
- Скан без текстового шару отримує статус «без тексту». Перейменований чи переміщений файл не стає новим.

### Веб-статті й закладки браузера

Меню → 2 → 3 → по одному в рядку: посилання або шлях до файлу — HTML-експорт закладок Chrome, Edge, Firefox,
Safari (теки стають списками), експорт Pocket (HTML, CSV), Instapaper (CSV), будь-який CSV зі стовпцем `url`
або TXT з посиланнями.

- Береться лише основний текст сторінки (без меню, реклами й коментарів), з назвою, автором і датою.
  Посилання на PDF читається як книга, на YouTube — як відео.
- Сторінки, якої більше немає, і сторінки без тексту (вхід, платний доступ) отримують «без тексту»;
  тимчасові помилки сайту — повтор пізніше.
- **Лише потрібні теки.** Після файлу закладок програма показує теки з кількістю посилань: номер — вибрати
  (з вкладеними), `>номер` — відкрити, `<` — назад, Enter — готово. Командою: `--only "Читати/Наука"`.
- Файл можна перезберегти з браузера — додадуться лише нові посилання.

### Raindrop.io

1. **Токен:** <https://app.raindrop.io/settings/integrations> → «Create new app» (назва будь-яка) →
   відкрити створену програму → «Create test token».
2. Меню → 2 → 4 → вставити токен (його не видно; перевіряється й зберігається у `.env`) → вибрати колекції
   або Enter — усі закладки.

Колекції стають списками («Наука/Фізика»), «Несортовані» — без списку. Програма лише читає закладки.

### Telegram

**Публічні канали** — просто за посиланням: меню → 2 → 5 → 2 → `t.me/назва` (або `bdig add t.me/назва`).
Без входу й без експорту; нові публікації додаються самі під час оновлень, старі великого каналу — частинами.

**«Збережене», приватні канали (зокрема ваші для нотаток), групи** — без входу в обліковий запис, з експорту Telegram Desktop: **Налаштування → Розширені → Експорт даних
Telegram** (весь обліковий запис, зокрема «Збережене») або в чаті **⋮ → Експорт історії чату**; формат —
HTML (за замовчуванням) або JSON. Позначте файли, якщо потрібні й документи, аудіо та голосові. Далі меню → 2 → 5 → тека експорту
(де лежить `export_results.html` чи `result.json`) → вибрати чати або Enter — усі. Або командою:

```bash
bdig add "D:\Telegram Desktop\DataExport_2026-10-31" --only "Збережене"
```

- Посилання на YouTube стають відео, інші посилання — статтями; посилання на інші пости Telegram пропускаються.
- Пости від 800 символів конспектуються як окремі тексти; документи й книги — як файли з папки; аудіо,
  відео й голосові — з розпізнаванням мовлення.
- Кожен чат — окремий список. Новіший експорт у ту саму теку додасть лише нове. Те саме відео, що вже
  є в іншому джерелі, вдруге не конспектується.

## Сортування, індекс, експорт

**Сортування за темами** (меню → 4 → список):
- **Мої теми** — теми й підтеми пишете ви (відкривається Блокнот / TextEdit / nano; підтема — з відступом);
- **Важливість** — кошики на зразок «Важливо, Різне» за вашим правилом словами;
- **Авто** — модель пропонує дерево тем, його можна виправити.

Можна додати критерії (зміст, цінність, глибина, обґрунтованість) і свої правила словами. Спершу —
попередній перегляд, нотатки переносяться лише після згоди. На 40 конспектів — один запит до моделі.
Схема запам'ятовується: нові конспекти списку розкладаються в її теми самі.

**Звіт та індекс.** Одним запитом модель визначає головну тему списку, групи повторів (✅ на найкращому)
і що не в темі. У теці списку з'являється нотатка `_Індекс — <список>.md`; після кожної обробки вона
оновлюється сама.

**Експорт у Raindrop.io** (меню → 5 або `bdig export`): окрема коренева колекція «Backlog digest», усередині —
списки й теми. Повторний експорт надсилає лише нове й змінене. Ваші закладки не змінюються, а колекція
експорту не імпортується назад.

## Питання до бібліотеки

Меню → 9 або `bdig ask "питання"`. Модель знаходить конспекти, що відповідають на питання, і пише відповідь
з посиланнями [1], [2]… — кожен номер веде на нотатку. Окремо: джерела, що повторюють одне одного (✅ на
найкращому), суперечності й сумнівні твердження, наскільки відповідь обґрунтована і чого в бібліотеці
немає. Відповідь зберігається нотаткою в теці `_Питання` сховища. Спершу модель бачить лише короткі описи
конспектів, тож і велика бібліотека — це кілька запитів. `--source N` — лише одне джерело.

## Бібліотека в Claude, Cursor та інших помічниках (MCP)

`bdig mcp` — MCP-сервер: помічник може шукати у ваших конспектах, відкривати будь-який повністю, бачити
джерела й ставити питання до бібліотеки. Пошук і читання нічого не коштують; лише «питання до бібліотеки»
витрачає ліміти ваших моделей. Помічник лише читає й нічого не змінює.

- Claude Code: `claude mcp add backlog-digest -- bdig mcp`
- Claude Desktop, Cursor та інші: `bdig mcp --config` показує блок, який треба вставити в їхні налаштування
  (`mcpServers`); помічник сам запускатиме програму.

## Розклад

Меню → 6: що робити (оновити списки → конспекти → звіт → Raindrop), скільки, щодня чи раз на тиждень,
«не раніше ГГ:ХХ». Автозапуск — системним планувальником без прав адміністратора: Планувальник завдань Windows
(без вікна), launchd на macOS, таймер systemd або cron на Linux. Комп'ютер був вимкнений — завдання
наздожене при наступному ввімкненні. Паралельно не запускається; журнал — у файлі й у нотатці
«_Журнал розкладу».

## Команди

Усе є в меню (`bdig`); те саме командами — зручно для скриптів:

```bash
bdig add "https://www.youtube.com/playlist?list=..." --name "Наука"   # джерело YouTube
bdig add "D:\Книги"                                                  # тека з книгами
bdig add bookmarks.html --only "Читати/Наука"                        # закладки, одна тека
bdig add raindrop "Читати пізніше"                                   # колекції Raindrop
bdig sync                     # знайти нове в усіх джерелах
bdig process --limit 20       # зібрати тексти й зробити конспекти
bdig fetch --limit 30         # лише зібрати субтитри
bdig summarize                # лише конспекти із зібраного
bdig export                   # конспекти — у Raindrop
bdig ask "Чому важливий глибокий сон?"   # відповідь з ваших конспектів, з посиланнями
bdig mcp --config             # бібліотека для Claude, Cursor (MCP)
bdig run-jobs --force         # виконати завдання розкладу зараз
bdig autostart on|off|status  # автозапуск розкладу
bdig --lang fr doctor         # перевірка французькою (uk, en, fr, es)
```

Ctrl+C зупиняє будь-якої миті, наступний запуск продовжить з того самого місця.

## Ваші дані — ваші

- Усе працює на вашому комп'ютері; конспекти — звичайні файли Markdown у вашій теці.
- Джерела лише читаються: у YouTube, закладках і Raindrop нічого не змінюється (експорт — в окрему колекцію).
- Ключі — у змінних середовища або у файлі `.env` у теці налаштувань; програма ніколи не показує їхні значення.
- Без телеметрії.

| Що | Windows | macOS | Linux |
|---|---|---|---|
| Налаштування `config.toml` і ключі `.env` | `%APPDATA%\backlog-digest` | `~/Library/Application Support/backlog-digest` | `~/.config/backlog-digest` |
| База, кеш, журнали | `%LOCALAPPDATA%\backlog-digest` | те саме | `~/.local/share/backlog-digest` |

`BACKLOG_DIGEST_HOME=<тека>` (або `bdig --home <тека>`) кладе все в одну теку.

Мова інтерфейсу (uk, en, fr, es) і мова конспектів (будь-яка) — окремі налаштування (меню → 8).
